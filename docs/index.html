楽天ROOM 候補ページ

楽天ROOMで紹介する商品を選ぶための、個人用の下書きツールです。

このツールについて

楽天ウェブサービスのランキングAPIで取得した商品情報をもとに、 レビュー評価などの条件に合う商品を毎朝数件選び、紹介文の下書きとあわせて 候補ページに表示します。

投稿は自動化していません。候補を見て楽天ROOMに投稿するかどうかは、運営者本人が判断し、手作業で行います。

利用しているデータ

  • 商品名
  • 価格
  • 商品画像
  • レビュー評価・レビュー件数
  • ランキング順位
  • 商品ページURL

取得したデータは候補ページの表示にのみ使用し、第三者への再配布・二次利用は行いません。
