Threads商品紹介 投稿支援ツール

楽天市場の商品情報をもとに、SNS投稿の下書きを作成する個人利用のツールです。

このツールについて

楽天ウェブサービスの商品検索APIで取得した商品情報をもとに紹介文の下書きを生成し、 運営者本人が内容を確認したうえで、自身のThreadsアカウントへ1日1件投稿しています。

利用しているデータ

  • 商品名
  • 価格
  • 商品画像
  • レビュー評価・レビュー件数
  • 商品ページURL（アフィリエイトリンク）

取得したデータは投稿の作成と本ページでの表示にのみ使用し、 第三者への再配布・二次利用は行いません。

広告表記について

投稿には楽天アフィリエイトのリンクを含みます。 景品表示法（ステルスマーケティング規制）に基づき、 すべての投稿の冒頭に #PR を表示しています。

運営者への連絡

本ツールに関するお問い合わせは、GitHubリポジトリのIssueよりお願いします。
