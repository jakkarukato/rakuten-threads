# 楽天ROOM 候補ページ

楽天の売れ筋ランキングから条件に合う商品を毎朝選んで、スマホで見られる**候補ページ**を作ります。
**投稿はしません。** 「ROOMに投稿」を押して紹介文を貼るのは本人です（楽天ROOMは機械的な投稿を禁止しています）。

候補ページ: https://jakkarukato.github.io/rakuten-threads/room/

## 仕組み

```
毎朝 6:00 (JST)  GitHub Actions が起動
  └ 4ジャンルの売れ筋ランキングを取得
      （レビュー4.0以上・30件以上・1,000〜50,000円）
  └ 60日以内に候補に出した商品は除く
  └ ジャンルごとに2件、紹介文の下書きを作る（スペック・価格・レビュー数など事実だけ）
  └ docs/room/index.html を更新 → GitHub Pages に公開
```

## 使い方

1. 候補ページを開く（スマホのホーム画面に追加しておくと楽）
2. 気になる商品の「紹介文をコピー」を押す
3. 「商品ページを開く」から楽天で「ROOMに投稿」を押し、コメント欄に貼って投稿する

すぐに候補を見たいときは、Actions の「楽天ROOMの候補ページを更新」を手動で実行します。
手動で何度も実行すると、そのたびに候補が「出した扱い」になるので、翌日以降の候補が減ります。

## 設定

| 変えたいもの | 場所 |
|---|---|
| 1ジャンルあたりの件数、同じ商品を出さない日数、PR表記 | `src/room.mjs` の `ROOM` |
| ジャンル、価格帯、レビューの条件 | `src/config.mjs` の `genres` と `filter` |
| 実行時刻 | `.github/workflows/room.yml` の cron（UTC指定） |
| スペックの抽出、専門用語の言い換え | `src/templates.mjs` |

## 必要な Secrets

| 名前 | 値 |
|---|---|
| `RAKUTEN_APP_ID` | 楽天ウェブサービスの applicationId |
| `RAKUTEN_ACCESS_KEY` | 楽天ウェブサービスの accessKey |
| `RAKUTEN_AFFILIATE_ID` | 楽天アフィリエイトID |

## 守ること

- **投稿を自動化しない。** 楽天ROOMの規約で、プログラムによる機械的な投稿は禁止されています
- **使っていない商品を「使った」と書かない。** 楽天アフィリエイトの禁止事項（事実に反する表現）です
- **オリジナル写真は自分で撮ったものだけ。** ネットの画像は審査を通らず、著作権侵害にもなります
- **知り合い同士で相互購入しない**
- 紹介文の下書きには `【PR】` を付けていません（`src/comment.mjs` の `prLabel`）。楽天アフィリエイトの公式ガイドラインでは、通常のアフィリエイト投稿のPR表記は任意です。**商品提供・イベント参加・アフィリエイター向けお試しクーポンの利用があった商品は【PR】が必須**なので、候補ページの各商品にある「無料提供・イベント参加・お試しクーポン利用の商品」にチェックを入れると、紹介文の先頭に【PR】が付きます（チェックを外すと消えます）

## 経緯

2026年9月まで、このリポジトリは Threads への自動投稿に使っていました。
作ったばかりのアカウントから短期間に商品リンク付きの投稿を重ねたところ、
Threads アカウントが永久停止されたため、投稿を人の手に戻す形に作り変えました。
当時のコードは git の履歴に残っています。

## 技術メモ

- **楽天の新APIは `Origin` ヘッダーで照合される。** エラーメッセージは REFERRER と言うが、`Referer` だけでは 403 になる
- **ランキングAPIのパスは `/ichibaranking/api/`。** 商品検索（`/ichibams/api/`）と接頭辞が違う
- **キーワード検索は精度が低い。** 商品説明の店舗テンプレートにヒットして無関係な商品が返るため、ジャンル指定のランキングを使っている
- **`itemCaption` は使わない。** SEO用のキーワード羅列、特定商取引法の表記、測定条件の注釈などが混ざり、フィルタで取り切れなかった
- **スペックは商品名から取る。** 「|」以降のキーワード列と【】内が材料。販促の【】（クーポン期間など）はブロックごと捨てる
- **公開リポジトリは60日間活動が無いとスケジュール実行が止まる。** 毎日のコミットで回避している
